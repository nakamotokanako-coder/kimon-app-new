# kimon-app

命名鑑定書アプリ。

## Stack

- React
- Vite
- Vitest
- Papaparse

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Test

```bash
npm test
```

## Build

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```

## Data

`data/` 配下の CSV / JSON はアプリで使用するprivateデータです。
このリポジトリは必ず GitHub private repository として運用します。
