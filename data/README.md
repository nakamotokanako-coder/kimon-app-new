# 奇門遁甲アプリ 開発パッケージ v3 LITE

**◯◯先生（流派監修・共同開発）と一緒に開発する奇門遁甲Webアプリ**の資料パッケージ。
プロジェクトナレッジに乗せられるサイズに最適化済（合計約1MB）。

## 中身

```
kimon_lite/
├ SPEC.md                       ← 仕様書（必読）
├ README.md                     ← このファイル
├ koyomi.csv                    ← 万年暦CSV（2020-2044の24年分, 713KB）
├ chito_ase_to_namida.csv       ← 完全展開盤テーブル（先生提供, 313KB）
├ kimon_tables.json             ← 紫白星9パターン（6.3KB）
└ test_case_2025-12-05.json     ← TDD用の正解値（年・月・日3盤）
```

## v3 LITEの軽量化ポイント

| 項目 | v2 → v3 LITE |
|---|---|
| 合計サイズ | 13.6MB → **1.04MB**（13分の1） |
| 暦DB期間 | 1900-2044（144年）→ 2020-2044（24年） |
| 列 | 全49項目 → 13項目（必須のみ） |
| 形式 | JSON.gz → CSV |

## Claude Codeで開始する手順

1. このフォルダごとプロジェクトディレクトリにコピー
2. Claude Code に以下を貼って起動：

```
このフォルダ kimon_lite/ にある SPEC.md を読んで、
Cフェーズ（盤組立エンジンの JS 実装）を TDD で進めてください。

ゴール:
  buildBoard({date: "2025-12-05", boardType: "日"})
  → test_case_2025-12-05.json の boards.日盤 と完全一致

メイン処理は chito_ase_to_namida.csv からの lookup のみ。
旋回ロジック等は不要。CSV読み込みは PapaParse 推奨。

最初のステップ:
  Step 1〜4（CSV読み込み → lookup → 日盤一致確認）まで
```
