# 稀日（めったにない盤のお知らせ） v1

2026-10-07 決定。めったにない盤が近づいたら、ホームとベルで知らせる。

## 呼び名（このアプリだけの造語）

| 名前 | 読み | 意味 | 条件 | 出る回数 |
|---|---|---|---|---|
| 満盤 | まんばん | 点数が満ちた盤 | 時盤で、特別格局が乗った方位が満点の120点（深夜・早朝も入れる） | 年に約18回 |
| 極盤 | きょくばん | 日盤が極まる日 | 日盤で、特別格局が乗った方位が100点以上（双格の日は除く） | 年に約7回 |
| 双格 | そうかく | 格局が2つ並ぶ日 | 日盤で、特別格局が2つ並ぶ | 年に4回だけ |

- 特別格局は、格局検索で選べる12個（青龍返首・飛鳥跌穴・九遁・玉女守門）。
- 双格と極盤が重なる日は、双格として出す。
- 名前は効果を約束しない言葉にした（「開運日」「最強日」のような名前は使わない）。すごさは、実際に数えた回数で伝える。
- 「天盤」「地盤」は奇門遁甲にもとからある言葉なので、「◯盤」の名前はそれと重ならないものにした。

## 回数の数え方

アプリで日盤を出せる期間（2026-01-01〜2044-01-31・18.1年）の盤を、全部数えた。使える方位（40点以上）だけを数える。

| 種類 | 18.1年で | 1年あたり |
|---|---|---|
| 満盤 | 332回 | 18.4回 |
| 極盤 | 128日 | 7.1日 |
| 双格 | 72日 | 4.0日 |

- 日盤で2つ並ぶ組み合わせは4種類だけで、どれも年に1回: 天遁＋神遁、雲遁＋虎遁、雲遁＋鬼遁、青龍返首＋鬼遁
- 青龍返首と飛鳥跌穴が同じ盤に乗ることは、時盤3年・日盤17年で一度も無い（お知らせや宣伝の文に書かないこと）

### 先に数えておいた表

数えた結果は `src/reverseDirection/rareDays.generated.js` に入れてある（532件）。画面はこの表を引くだけ。
1年ぶんの時盤（4,380盤）をその場で数えると数秒かかり、「今年はあと何回」をすぐ出せないため。

- 作り直す: `npm run build:rare`（25秒ほど）
- 点数の表・格局の判定・暦を変えたら、作り直す。`test/rareDays.test.js` が、表と実際の盤のずれを見つける

### 画面に出す数字

- **年に約18回**（種類ごとの1年あたりの回数）… `RARE_TIERS` に書いてある。上の表を四捨五入したもの
- **今年は、この回を入れてあと◯回**… その年（1月1日〜12月31日）のうちに、同じ種類があと何回出るか。表から数える。最後の回は「今年は、これが最後」
- **この次に出るのは◯日後**、**これから12週間のうち出る週**… 表から数える

### 深夜の時間帯

23-1時の時間帯は、盤の日付では「次の日」の先頭に数える（アプリは夜11時に日付を進める）。
始まるのは前の日の夜11時なので、画面には「7/26（月）23:00–翌1:00」と書き、「あと何日」「今年」も始まる日で数える。

## 知らせ方

- **3日前から当日まで**出す。満盤は、その時間帯が過ぎたら消える。深夜・早朝の満盤も出す。
- **ホームのいちばん上**: 金の枠のカード（印・あと何日・回数・一言・日時と方位・格局の絵）。いくつかあるときは、いちばん珍しいものを1つ。
- **ベル**: 「あと3日で『満盤』です」「明日は…」「今日は…」。稀日ごとに1件。
- **開いたときの画面**: 格局の絵 → 印と日時 → 方位 → どのくらい珍しい？（回数・この次に出るのは・12週間の帯）→ 格局の案内（一言・説明・こんな日に3つ）→ この方位を地図で見る
  - 地図は、満盤なら時盤、極盤・双格なら日盤で、その日時・方位のまま開く
