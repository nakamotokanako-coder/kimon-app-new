# 稀日（めったにない盤のお知らせ） v1

2026-10-07 決定。めったにない盤が近づいたら、ホームとベルで知らせる。

## 呼び名（このアプリだけの造語）

| 名前 | 読み | 意味 | 条件 | 出る回数 |
|---|---|---|---|---|
| 満盤 | まんばん | 点数が満ちた盤 | 時盤（朝5時〜夜11時）で、特別格局が乗った方位が満点の120点 | 年に約18回 |
| 極盤 | きょくばん | 日盤が極まる日 | 日盤で、特別格局が乗った方位が100点以上 | 年に約9回 |
| 双格 | そうかく | 格局が2つ並ぶ日 | 日盤で、特別格局が2つ並ぶ | 年に4回だけ |

- 特別格局は、格局検索で選べる12個（青龍返首・飛鳥跌穴・九遁・玉女守門）。
- 双格と極盤が重なる日は、双格として出す。
- 名前は効果を約束しない言葉にした（「開運日」「最強日」のような名前は使わない）。すごさは、実際に数えた回数で伝える。
- 「天盤」「地盤」は奇門遁甲にもとからある言葉なので、「◯盤」の名前はそれと重ならないものにした。

## 回数の数え方（2026-10-07 から。使える方位＝40点以上だけを数える）

- 時盤3年（朝5時〜夜11時・9,855盤）: 特別格局つきの120点は53回 → 年に約18回
- 日盤17年（6,300日）: 特別格局つきの100点以上は157日 → 年に約9回。2つ並ぶ日は68日 → 年に4回
- 日盤で2つ並ぶ組み合わせは4種類だけで、どれも年に1回: 天遁＋神遁、雲遁＋虎遁、雲遁＋鬼遁、青龍返首＋鬼遁
- 青龍返首と飛鳥跌穴が同じ盤に乗ることは、時盤3年・日盤17年で一度も無い（お知らせや宣伝の文に書かないこと）
- 時盤で3つ以上が同じ時間帯に重なることは、朝5時〜夜11時では一度も無い

画面に出す「年に約18回」などは、この数えた結果を `src/reverseDirection/rareDays.js` の `RARE_TIERS` に書いてある（毎回は数え直さない）。
「この次に出るのは◯日後」と12週間の帯は、開いたときに実際の盤から数える。

## 知らせ方

- **3日前から当日まで**出す。満盤は、その時間帯が過ぎたら消える。
- **ホームのいちばん上**: 金の枠のカード（印・あと何日・回数・一言・日時と方位・格局の絵）。いくつかあるときは、いちばん珍しいものを1つ。
- **ベル**: 「あと3日で『満盤』です」「明日は…」「今日は…」。稀日ごとに1件。
- **開いたときの画面**: 格局の絵 → 印と日時 → 方位 → どのくらい珍しい？（回数・この次に出るのは・12週間の帯）→ 格局の案内（一言・説明・こんな日に3つ）→ この方位を地図で見る
  - 地図は、満盤なら時盤、極盤・双格なら日盤で、その日時・方位のまま開く
