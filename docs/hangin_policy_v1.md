# 反吟の扱いと、同じ名前で意味が違う十干剋応 v1

2026-10-03 決定。監修者の判断を仰げないため、古典と現行の流派解説を根拠に決めた（空亡などは `palace_veto_policy_v1.md`）。

## 1. 反吟

### 発端
2026-10-02 の日盤（星反吟）で、解説エンジンは8方位×5テーマをすべて × にしていた一方、総合スコアは −10 点だけで震宮が +50（大吉）だった。

### 資料の記述
- 《煙波釣叟歌》: 伏吟・反吟について「八門返伏皆如此、生在生兮死在死」。伏吟・反吟でも門の性質（生門は生、死門は死）は残る。
  凶宿は奇門を得ても「萬事皆凶不堪使」。https://zh.wikisource.org/zh-hant/煙波釣叟歌
- 現行の流派解説: 反吟は「速い・反復・変動・行って戻る」。出行は途中で引き返すことがある。
  三奇や吉門に逢えば必ずしも災いにならない。伏吟は「停滞。動かず守るのが吉」。
  https://zhuanlan.zhihu.com/p/639375457 / https://m.yi958.com/qimen/posts/13411

### 決定（`src/kaisetsu/classifyPalace.js`）
| 状態 | 変更前 | 変更後 |
|---|---|---|
| 反吟・三奇＋吉門なし | 総合は▲まで、5テーマは全部 × | 門・星の性質を残す。◎だけ○に抑える（凶はそのまま） |
| 反吟・三奇＋吉門あり（vetoRelief） | 総合は△まで、5テーマは全部 △ | 抑えない（通常どおり） |
| 伏吟 | 総合は▲まで、5テーマは ×（金運のみ△） | 変更なし（「動かず守る」は資料と合う） |

- 総合スコアは従来どおり盤全体 −10 点。反吟の日は解説文の主役が「物事が反転しやすい反吟の日。予定の変更や出戻りを見込んで」になる。
- 空亡＋吉門の救済（遅効）は、反吟・伏吟の日には適用しない（従来どおり）。

### 影響
- 全1080局のうち反吟は221局（1,768宮）。変更前はほぼ全宮が全テーマ ×。
  変更後は 909宮で吉のテーマが出る。全テーマ × のままは 628宮（死門・拒否権など）。

## 2. 同じ名前で意味が違う十干剋応

天盤×地盤の組み合わせが違うのに同じ名前の十干剋応が3つある（`shoui_dict.json` の no）。

| 名前 | 組み合わせ | 意味 |
|---|---|---|
| 華蓋孛師 | 74: 癸＋丙 | 吉。身分に関係なく喜び事がある |
| 華蓋孛師 | 18: 丙＋癸 | 凶。悪いことが続けて起きる |
| 華蓋蓬星 | 73: 癸＋乙 | 中立。立場のある人は身分向上、一般の人は平穏 |
| 華蓋蓬星 | 9: 乙＋癸 | 中立。身を引いて難を避けるのに向く |
| 凶蛇入獄 | 62: 辛＋壬 | 凶。三角関係のような利害。先に動くと不利 |
| 凶蛇入獄 | 68: 壬＋己 | 凶。大きな災い。守りに徹する |

盤データ（CSV）の吉凶は正しかったが、解説文の文言バンクと盤のシートが名前だけで文言を引いていたため、
丙＋癸（凶）の華蓋孛師に「喜び事」の文が出るなど取り違えていた。

- `classifyPalace` が宮の天盤・地盤から組み合わせ番号を出す（`shouiVariant`）。
- 文言バンクは `shoui[名].variants[no]` に組み合わせ別の総論・5テーマの文を持つ。`composeText` はそれを引く。
- 盤のシート・吉方位の詳細シートの「評価の解説」は、天盤×地盤で象意辞書を引く（`palaceExplain.js`）。
