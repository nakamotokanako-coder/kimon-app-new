# 総合点とテーマ別の◎○×を揃える v2

2026-10-06 決定。`axis_score_mismatch_v1.md`（食い違いの調査）の続き。監修者の判断を仰げないため、
講座の点数表と古典・現行の解説を根拠に決めた（空亡などは `palace_veto_policy_v1.md`、反吟は `hangin_policy_v1.md`）。

## 発端

目的（ご縁・仕事・金運・健康・勉強）から方位を探す機能を足す前に、総合点とテーマ別の◎○×の食い違いを無くす。
テーマで探せるようにすると、「仕事◎で出てきた方位の総合点がマイナス」が表に出るため。

## 変更前の実測（時盤 2026〜2027年・8方位×12時間帯＝70,080件）

| 食い違い | 件数 | 原因 |
|---|---|---|
| 総合が中立・凶なのに、テーマに◎か○がある | 48,673件中 13,907件（29%） | テーマ別は門・星・神・象意の足し算だけで、総合の吉凶を見ていなかった |
| 総合が吉・大吉なのに、◎も○も無い | 21,407件中 2,956件（14%） | うち 2,802件が伏吟の盤（テーマ別を金運以外すべて×にしていた） |

## 決定

### 1. 総合点を主にする。テーマ別の◎○×は総合点を超えない

| 総合点 | 吉凶バッジ | テーマ別の上限 |
|---|---|---|
| マイナス、または三大凶格 | 凶 | ▲まで |
| 0点 | 中立 | △まで |
| 1〜39点 | 吉 | ○まで |
| 40点以上 | 大吉 | ◎まで |

- 総合点は講座の点数表（第6章 p78-81）が出典で、監修も入っている。テーマ別の傾き（`GATE_AXIS` など）は暫定値のまま。
- 講座の目的別ルール（p79）も「使える方位の中から、門で目的を選ぶ」という順番で、総合が先に立つ。
- 総合が吉でテーマ別に×や▲が付くのは食い違いではない（例: 総合は吉だが、玄武が入るので金運には向かない）。
- 解説文は◎○×から作るので、文章の吉凶も一緒に揃う。総合が凶で吉門の方位は「本来は〜に向く門です。しかし…」の文になる。
- 総ランク（`rank`）にも同じ上限を掛ける。`palace_veto_policy_v1.md` の残課題
  「総ランク◎なのに5軸がほぼ×（乙奇得使＋死門）」はこれで無くなる。

### 2. 伏吟は、門・星の性質を残して◎だけ○に抑える（反吟と同じ扱い）

変更前は、伏吟の盤のテーマ別を金運以外すべて×にしていた。総合点は講座どおり全方位 −10点だけなので、
「総合は大吉、テーマは全部×」になっていた。

資料の記述は割れている。

| 資料 | 記述 |
|---|---|
| 現行の流派解説（易德轩） | 「伏吟主不宜出行，主不能妄動」「宜收斂錢財、討債催款」。ただし「若不遇吉門吉格更凶，如遇吉門吉格為有救」 |
| 《煙波釣叟歌》の解説 | 「惟宜收斂貨財，慎勿輕舉妄動」。「八門返伏皆如此、生在生兮死在死」（門の性質は残る） |
| 日本の立向盤の実践（ktonko.com） | 「吉方位になる場合には、伏吟反吟系や補足系の凶格局は考慮せずに活用できる」 |
| 講座の点数表 | 全方位 −10点（干伏吟・星伏吟・門伏吟それぞれ） |

- https://m.yi958.com/qimen/posts/7349
- https://m.sohu.com/a/529624538_324894/
- https://ktonko.com/html/syoi/32_kyo.html

共通するのは「吉門・吉格がある方位は使える。無い方位は凶」。そこで:

- テーマ別の全部×をやめ、門・星の性質を残す。停滞の日なので◎は出さず○まで。
- 吉門・吉格の救いが無い方位は総合点がプラスにならないので、1 の上限でテーマ別も▲までになる。
- 総合点は講座どおりで変えない。解説文には「伏吟の日のため、足踏みと停滞には注意が必要です」が入る。
- `hangin_policy_v1.md` の「伏吟: 変更なし」は、この決定で置き換える。

### 3. 日付で決まる凶は、画面で上限を掛け直す

解説文と◎○×は「局と干支」ごとに作ってある。総合点には日付で決まる分があり、解説側からは見えない。

- 歳格・月格（年・月の干）、時盤の日格・伏干・雲干（日の干）、時盤の五不遇時（日の干×時の干）、順利の +20

そこで画面に出すときに、その日時の総合点からもう一度上限を掛ける（`FusionCard.computeAxisRanks` の第3引数）。
解説の文より◎○×が下がった方位には「この日時だけの凶が重なっているので、◎○×は解説の文より低く出しています。」と添える
（`dateCapNote`）。日盤は日の干が鍵に入っているので、日格・伏干・雲干までは解説側で見ている。順利の +20 では上げない。

## 実装

- `src/kimon/palaceScore.js` … 1宮の点数表と拒否権の上限（`scoreEngine.js` から切り出し。盤データの読み込みに依存しない）
- `src/kaisetsu/classifyPalace.js` … `baseTotal`（局と干支だけで決まる総合点）、`axisCapForTotal`、`capAxisRanks`。
  判定オブジェクトに `totalScore` `totalCap` を足した
- `src/reverseDirection/FusionCard.jsx` … `computeAxisRanks(key, palace, palaceScore)`、`dateCapNote`
- `scripts/build_kaisetsu_text.mjs` … 日盤用の解説は、◎○×が時盤と変わる宮も作り直す
- `test/axisScoreAlignment.test.js` … 1年ぶんの盤で、◎○×が総合の吉凶バッジを超えないことを確かめる

総合点そのものは1点も変えていない（`scoreBoard` の結果は同じ）。

## 変更後の実測（同じ70,080件）

| | 変更前 | 変更後 |
|---|---|---|
| 総合が中立・凶なのに、テーマに◎か○がある | 13,907件 | 0件 |
| 総合が吉・大吉なのに、◎も○も無い | 2,956件 | 154件 |
| 日付で決まる凶のために、解説の文より◎○×を下げる | — | 1,333件（1.9%） |

- 残る154件は、凶門に吉の象意が乗って点数だけプラスになった方位など。テーマ別はどれも△以下で、「特に向くテーマが無い」という読みになる。
- 解説文 43,200件の内訳は、吉 9,304 → 7,201件、中立 11,419 → 7,027件、凶 22,477 → 28,972件。
- テーマごとに、◎か○の方位が1つでもある時間帯の割合（時盤）: ご縁 85%、仕事 83%、金運 86%、健康 88%、勉強 68%。

## 残課題

- テーマ別の傾き（`GATE_AXIS` `STAR_AXIS` `GOD_AXIS` `SHOUI_AXIS`）は暫定値のまま。講座の目的別ルール（p79）は
  健康を休門に置くが、こちらは生門 +2・休門 +1 としている。監修者に確認できるときに見直す。
- 日付で決まる凶で◎○×を下げた方位は、解説の文が吉のまま残る（一言を添えて知らせている）。
