# お守り v1（吉方位へ行けない日の取り入れ方）

2026-10-04。旧「開運のお守り」（最強方位から、理由を伏せて一言をランダムに出す）を、考え方ごと作り直した。

## 考え方
「行けるなら、吉方位へ。行けないなら、吉を取り入れる。」
吉方位へ実際に動けないときに、その吉方位の象意を、物・色・行動として日常に取り入れる提案。ランダムなラッキーアイテムではない。

盤 → 一番点数の高い吉方位 → その方位の象意（八卦の定位）と、入っている門 → 取り入れるもの

- 方位の象意 … どの候補（方位ごとに6つ）から選ぶか
- 門 … 候補のうち、どの種類を先に勧めるか（休門・生門＝口にするもの、開門＝持ち物・行動、景門＝色・装い、その他＝身につけるもの）
- 同じ盤なら同じ結果。吉の方位が無い盤では出さない（凶方位の象意からは作らない）

## 日盤と時盤
| | 日盤 | 時盤 |
|---|---|---|
| 名前 | 今日のお守り | この時間のお守り |
| 期間 | 1日固定 | その時辰の間 |
| 場所 | ホーム、日盤（遠出）の画面 | 時盤（今から吉方位へ）の画面 |

エンジンは共通（`src/kimon/charm.js` の `getCharm`）。表示は `src/components/CharmCard.jsx`。

## 文言の決まり
- 「見る」。「引く」「ガチャ」「当たり」は使わない。
- 効果を言い切らない。「凶を消す」「無効にする」「和らげます」と書かない。「〜を取り入れる」「〜という考え方」。
- 吉方位へ動くことの代わりではなく、補助的な取り入れ方として書く。
- 専門の根拠（方位・門・神・星・象意・選んだ理由）は「なぜこれがお守りになる？」を開いたときだけ出す。

## 中身の出どころ
象意と候補（`CHARM_LIBRARY`）は、`data/kyusei_shoui.json`（方位ごとの色・持ち物・食べ物・行動・天候の持ち物）をもとに、
落ち着いた言い回しに整えたもの。旧お守りの一言（同ファイルの `omamori`）と締めの言葉は使っていない。
