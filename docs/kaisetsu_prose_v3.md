# 解説文 v3（4段落の文章）

2026-10-03。運営者が承認した見本（`docs/kaisetsu_rewrite/approved_samples.md`）の書き方に、解説文を全面的に書き直した。

## 文章の形
1. **見出し**（太字）… その方位の使い方を一言で
2. 主な理由 … 門と拒否権（伏吟・反吟など）。「〜の影響で → 一方で」とつなぐ
3. 神と星 … 支える要素を先に、注意する要素を後に
4. 象意の1文 ＋ **しめ**（太字）… 「〜ために使いたい方位」

- short = 見出し（未ログインにも出る）／ mid = 見出し＋主な理由（吉方位タブのカード）／ full = 4段落（盤のポップアップ・吉方位タブの詳細）
- 段落は空行、太字は `**…**`。画面は `src/kaisetsu/renderProse.jsx` で描く。

- 文章の吉凶は、必ずテーマ別の◎○×（軸ランク）に合わせる。判定（`classifyPalace.js`）は変えていない。
- 43,200件を1件ずつ書かせるのではなく、**部品だけを書き直して、組み合わせはルールで決める**。判定と文章がずれないようにするため。
- 門・神・星・拒否権の部品は Codex（gpt-5.5）に `docs/kaisetsu_rewrite/codex_brief_bank_v3.md` の依頼書で書かせた。
  象意の文は、意味を変えないよう v1 の文の語尾だけを規則で です・ます調に変えている。

## 主な出し分け
| 場面 | 書き方 |
|---|---|
| 吉（◎○） | 門の使い方 → 神・星 → 象意 → しめ。凶の要素は「ただし、〜には注意が必要です」（「ただし」は全体で1回） |
| 吉だが凶門で、吉の象意がある | 象意を主役にする（門の限定的な使い道を見出しにすると象意と食い違うため） |
| △ | 拒否権があれば「〜の影響で…。一方で、門は〜には使えます」 |
| 凶（▲×）・吉門 | 「門は本来〜に向く門です。しかし、…」。吉の神・星は「本来は〜だが力を出しきれません」 |
| 凶（▲×）・凶門 | 拒否権 → 門の凶意。しめで「〜なら限定的に使えます」 |

## 時盤と日盤で解説を分ける（2026-10-04）
- **時格・天羅・地網**は「時の干」で決まる格局。日盤には時の干が無いので、点数の計算（`src/kimon/kakkyoku.js`）は日盤でこの3つを数えない。
  解説文と◎○×もそれに揃え、日盤ではこの3つを外して判定・作文する（`classifyPalace(row, palace, { boardType: '日' })`）。
- 解説の鍵は `src/kaisetsu/boardKey.js`。日盤のときだけ「陰1局丁卯@日」のように印を付ける。画面も API もこの鍵で引く。
- 生成物は、日盤で内容が変わる宮だけを `__day` に持つ（全43,200件中、日盤用は2,515件）。配信時に時盤の内容へ上書きする（`lib/kaisetsuData.js` の `getBoard`）。
- **歳格・月格・日格・伏干・雲干**は年・月・日の干で決まるため、前もって作る解説文には入れられない。
  点数と格局の一覧には入っているので、文章の下に「この日時は◯◯が重なっています」と注記する（`src/kimon/palaceExplain.js` の `dateBoundNote`）。
