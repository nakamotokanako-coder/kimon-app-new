# 象意×テーマ別の文 一覧 v1（2026-10-02 確定・`kaisetsu_bank_v1.json` の `shoui.*.axes` に収録）

象意104種類×5テーマ＝520文の下書きです。解説文では、象意の**総論（1文目）**のすぐ後ろに、そのテーマの文が続きます。

- 口調: 柔らかい言い切り（「〜しやすい」「〜に向く」「〜したい」）。「〜しましょう」「〜かもしれません」は使わない
- 長さ: 1文 27〜56字（平均41字）
- 健康: 病院・検査・睡眠・運動など具体的な用事に寄せ、「治る」「良くなる」などの効果は書かない
- 根拠: 象意辞書（`data/shoui_dict.json`）の意味を各テーマに当てはめたもの。新しい吉凶は足していない
- 吉の象意はそのテーマが吉のとき、凶の象意は凶のときに使われる。**中立の象意（15種類）は今の仕組みでは本文に出ない**（今後△のテーマで使う想定で書いてある）
