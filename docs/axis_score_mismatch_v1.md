# 総合スコア(reverseDirection.js) と axisRanks(classifyPalace) の食い違い調査 v1

PR-2（統合カード）§1調査で判明した、2つの独立エンジンの検証記録。**監修者への確認資料であり、
エンジン修正のための資料ではない**（エンジン本体の修正・調整は本PRのスコープ外）。

## 背景

- 時盤お散歩モードの最大吉カードの「点数」「吉凶バッジ」は `reverseDirection.js`（`scoreEngine.js`）由来。
- 統合カードで新規に追加する「軸チップ（◎○△▲×）」「意味テキスト」は `classifyPalace.js`（kaisetsu）由来。
- 2つは完全に独立した実装であり、同じ局・宮に対して評価が食い違うケースがある。

## 検証方法

- 2026年の12ヶ月から各1日、1日あたり5時間帯（1時・9時・13時・17時・21時）＝ 60局面をサンプリング
- 各局面につき8宮ぶん、`scoreBoard()`の点数の符号（プラス/マイナス/0）と、
  `classifyPalace().rank`（◎○=吉→+1 / △=中立→0 / ▲×=凶→-1）の符号を突き合わせ
- 符号が一致しないものを「食い違い」としてカウント

## 結果

- 総チェック数：480件（60局面 × 8宮）
- 食い違い数：157件
- 食い違い率：32.7%

## 本PRでの扱い

- 点数・吉凶バッジは`reverseDirection.js`由来のまま維持し、軸チップ・意味テキストは`classifyPalace`
  （kaisetsu）由来を追加する「A案」を採用（別セッションでの承認事項）。
- UIでは軸チップ行に「テーマ別」ラベルを付け、総合点とは別評価軸であることを明示する。
- どちらのエンジンが正しいかの検証・修正は本資料の目的ではなく、別途監修者確認が必要な課題として記録する。
