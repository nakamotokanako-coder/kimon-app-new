# お守りの画像（48枚の一覧）

画像を入れると、お守りの名前の上に丸い画像が出ます。**何枚からでも始められます**（無いものは文字だけで出ます）。

## 作り方

1. 下の表の「ファイル名」で画像を作り、`image/charms/` に置く（例: `image/charms/son-1.png`）
2. `python scripts/build_charm_images.py` を実行する（正方形 640px・軽い形式に整えて `public/charms/` に出力）
3. コミットして出す

## 画像の決まり（そろえると統一感が出る）

- **正方形**で、**背景は透明**（物だけを切り抜いた画像）。お守りの紙の上に、そのまま置いたように出る
- **1枚に1つの物**。文字・ロゴ・人の顔・ブランド名が読める商品は入れない
- 画風は全部そろえる（今入っているのは、やわらかい光の写真風の切り抜き）
- 色のお守り（「黒・青のもの」など）は、その色の布や小物を1〜2点
- 行動のお守り（「少し歩く」など）は、人を写さず、物で表す（歩きやすい靴、など）
- 透明な余白は自動で切り落として、物を大きく見せる（`scripts/build_charm_images.py`）
