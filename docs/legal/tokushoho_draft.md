# 特定商取引法に基づく表記（下書き v1・未公開）

> **これは下書きです。** 有料で販売する場合、日本では特定商取引法に基づく表記の掲載が必要です。
> 【 】を埋めて、公開前に専門家に確認してください。Stripe の審査でも、この表記のページを求められます。

| 項目 | 内容 |
|---|---|
| 販売事業者 | 【氏名または名称】 |
| 運営責任者 | 【氏名】 |
| 所在地 | 【住所】。自宅の住所を載せない方法は3つ（要確認）：(1)「請求があれば遅滞なく開示します」と記載する (2) バーチャルオフィスの住所を載せる (3) 法律事務所など第三者の住所を載せる（その事務所との契約・同意が必要） |
| 電話番号 | 【電話番号】（同上） |
| メールアドレス | 【メールアドレス】 |
| 販売価格 | 月額980円（税込） |
| 商品代金以外の必要料金 | インターネット接続に必要な通信料は、お客様のご負担となります。 |
| 支払方法 | 【クレジットカード】 |
| 支払時期 | 申し込み時に初回の料金をお支払いいただき、以後【1か月】ごとに自動で請求されます。 |
| 提供時期 | 決済の完了後、すぐにご利用いただけます。 |
| 解約 | 【設定画面／所定の方法】からいつでも解約できます。解約後も、支払い済みの期間の終了日までご利用いただけます。 |
| 返品・返金 | デジタルサービスの性質上、支払い済みの料金の返金はお受けしていません（法令に定めがある場合を除く）。 |
| 動作環境 | 最新版の Safari、Chrome などのブラウザ |
