## 原因と修正（`src/kaisetsu/composeText.js`）

1. **文章の吉凶を総合ランクで決めていた。** 画面ではテーマ別◎○×（軸ランク）の直下に文が出るため、軸×の下に「追い風が吹く方位」が出ていた。
   → 結論・理由・注意・行動提案すべてを、そのテーマの軸ランク基準で組む。
2. **八門の文を吉凶に関係なく付けていた。** → 凶の軸では吉門（開・休・生・景）の軸フレーズ・使い道・総説を出さない。
   吉の軸では「〜には不向きだが…なら働く」のような否定を含むフレーズを出さない。凶門の「〜なら使えます」は凶の軸に残す。
3. **吉神の同居文・上吉星の褒め文を凶の軸にも付けていた。** → 凶の軸では出さない。
4. **天心の文言（通院や検査）を全テーマに付けていた。** → 健康のときだけ。
5. **◎昇格象意の絶賛文を中立・凶の軸でも主役にしていた。** → 吉の軸のときだけ。
6. **「この盤で最も」は他の宮と比較せずに出していた。** → 骨子を「{axis}に強い追い風が吹く方位。」に変更。
7. **2文を1文に畳むとき「です。」→「です、」になっていた。** → 「で、」でつなぐ（「。ただ、」は「だが、」）。
8. **言い換えの重複（hint と主役文、門の文と行動提案など）。** → 先に置いた文と8字以上同じ並びを含む文は落とす。
9. **拒否権が複数あると先頭（空亡）だけを語っていた。** → 三奇入墓・六儀撃刑などの重い方を優先。伏吟の例外「財の整理…だけは向く」は金運のときだけ。
10. **空亡の救済（#139）が伏吟・反吟の日にも効いていた。** → 盤全体が伏吟・反吟の日は救済しない（`classifyPalace` / `palaceVeto.js`）。

## 残課題（文言データ側）

- 象意の文言はテーマ非依存で書かれているため、テーマと関係の薄い内容が出ることがある
  （例: 健康のテーマに丙奇得使の「プレゼン・公表・PRの成果が大きく出る」）。象意ごとの軸別文言が必要。
- 総合ランク（◎昇格）と軸ランクが大きく離れる宮がある（例: 陰1局丙寅の坤＝総合◎だが全テーマ△）。
