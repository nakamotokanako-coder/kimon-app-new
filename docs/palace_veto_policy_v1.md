# 宮の拒否権（空亡・三奇入墓など）と総合スコアの扱い v1

2026-10-02 決定。監修者の判断を仰げない状況のため、古典と現行の流派解説を根拠に決めた。

## 発端

2026-10-02 15〜17時（陰6局壬申）の時盤お散歩で、北西（乾宮）が「+70・大吉」と表示される一方、
テーマ別の相性（ご縁・仕事・金運・健康・勉強）はすべて×だった。

- 乾宮は **空亡（戌亥）** かつ **丙奇入墓**（丙が戌＝火の墓に入る）に該当する。
- 総合スコア（`scoreEngine.js`）は加点式で、空亡は −10 点のみ・入墓は減点なし。飛鳥跌穴の加点が勝って +70 になっていた。
- 解説エンジン（`classifyPalace.js`）は空亡・三奇入墓を「拒否権」として 5 軸すべて × に固定していた。

## 決定

点数そのものは講座の加点式を保ち、拒否権に該当する宮だけ **上限** を掛ける（`src/kimon/palaceVeto.js`）。

| 該当 | 上限 | 表示 |
|---|---|---|
| 三奇入墓・六儀撃刑・五不遇時・天網四張（1つでも） | −20 | 凶 |
| 空亡のみ・吉門（開休生）なし | 0 | 中立（もともと凶ならそのまま） |
| 空亡のみ・開門/休門/生門あり | 上限なし | 点数そのまま。理由の先頭に「空亡（遅効）」。解説の◎○×は上限○ |

- 判定は `classifyPalace` の Level 1 拒否権と同一の関数を使う（解説側と食い違わせない）。
- 盤レベルの反吟・伏吟は従来どおり `ban_level_minus` の減点のみ（対象外）。
- `scoreBoard` 内で適用するため、盤画面・時盤お散歩・日盤遠出・ランキングすべてで同じ点数になる
  （`test/score_screen_match.test.js` の不変条件を保つ）。上限前の点数は `breakdown.pre_veto_score` に残す。
- 該当宮の `reasons` 先頭に拒否権名（「空亡」「三奇入墓」など）を出す。

## 影響（2026年・全日×時盤12時間帯の実測）

- 宮×時間帯 35,040 件のうち、点数に上限が掛かったもの 2,959 件（8%）。うちもともとプラス点だったもの 2,187 件。
- 空亡だが吉門で救われ点数そのまま（空亡（遅効））: 2,234 件。
- 「今の吉方位」1位が入れ替わる時間帯: 4,380 中 482（11%）。
- 参考: 空亡を吉門の有無にかかわらず一律 0 止まりにした初版では 970（22%）だった。

## 残課題

- （対応済み）解説エンジンも同じ条件に揃えた。空亡のみ＋開休生門の宮（全1080局×8宮中 551宮）は
  ×固定をやめて通常判定＋上限○、解説文は主役を空亡にせず「空亡の巡りのため、結果は少し遅れて届きやすい」で締める
  （`classifyPalace.kuubouRelief` / `composeText`・バンク `vetoes.空亡.relief`）。開休生門がない空亡は従来どおり×固定。
- 総ランク◎なのに 5 軸がほぼ × になるケース（例: 陰6局壬申の離宮＝乙奇得使＋死門）は別途点検が必要。
