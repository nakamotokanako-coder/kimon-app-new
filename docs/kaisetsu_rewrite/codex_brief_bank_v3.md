# 解説文の部品（v3）を書く依頼

奇門遁甲アプリの方位解説は「部品（短い文）をルールで組み合わせて」作っている。
その部品を、運営者が承認した新しい書き方（です・ます調、理由がつながる、最後に使い方でしめる）で書き直す。

- 承認済みの見本: `docs/kaisetsu_rewrite/approved_samples.md`（この口調・強さ・具体性に合わせる。強い言い切りでよい）
- 意味の出どころ: `data/kaisetsu/kaisetsu_bank_v1.json`（今の部品。**意味・吉凶の向きは変えない。盛らない。**）
- 他のファイルは読まなくてよい。コードは変更しない。**指定の JSON ファイルを1つ作るだけ。**

## 組み立て方（部品がどう並ぶか）

1つの解説は4段落。評価の向き dir は、吉(◎○)=pos / どちらでもない(△)=neu / 凶(▲×)=neg。

1. 見出し: `gates[門].head.pos|neu[テーマ]`、凶は `negHeads`
2. 主な理由（門と拒否権）
   - 拒否権なし: pos → `body.pos` ／ neu → `body.neu` ／ neg → 吉門は `body.honrai` + `mutedTail`、凶門は `body.neg`
   - 拒否権あり: pos → `body.pos`（拒否権は4段落目に `vetoes[..].caution`）
     ／ neu → `vetoes[..].body` + 「一方で、」+ `body.neu`
     ／ neg → 吉門は `body.honrai` + 「しかし、」+ `vetoes[..].body`、凶門は `vetoes[..].body` + `body.neg`
3. 神と星: `gods[神]` と `stars[星]` から、向きに合う1文ずつ
4. 象意の1文（別ファイル）+ しめ `gates[門].close.pos|neu|neg[テーマ]`

## 各部品の書き方

全部品共通: **です・ます調の完結した文**（1〜2文）。文末は「。」。門・神・星の名前を主語に出す。

| 部品 | 使われる場面 | 形・例 | 長さの目安 |
|---|---|---|---|
| `head.pos` | 吉の見出し | 「金運は、争いを整理し、権利のあるお金を取りに行く方位です。」テーマ名で始め、その門ならではの使い方を言い切る | 25〜40字 |
| `head.neu` | △の見出し | 「仕事は、大きく進めるより、閉じて守る作業に向く方位です。」＝「AよりB」の形 | 25〜40字 |
| `body.pos` | 吉の理由 | 「驚門は波風を立てる門ですが、金銭トラブルの示談や条件交渉、保険・補償の請求など、白黒をつける用事には強く働きます。」 | 45〜75字 |
| `body.neu` | △の理由。**先頭に「一方で、」が付いても自然に読めること** | 「杜門は、機密の保持、計画の温存、独りで籠もる作業には使えます。」 | 35〜65字 |
| `body.honrai` | 吉門なのに凶のとき | 「休門は本来、復習や読書、知識の整理に向く門です。」 | 25〜45字 |
| `body.neg` | 凶門で凶のとき。**先頭に拒否権の文が来ても自然に読めること** | 「驚門は声と動揺の門で、繊細な話し合いを持ち込むと口論を呼びやすい配置です。」 | 35〜65字 |
| `close.pos` | 吉のしめ | 「**「主張すべきお金を整理して取りに行く」ために使いたい方位**です。」太字の中に「」で使い方を入れる | 30〜50字 |
| `close.neu` | △のしめ | 「**「外へ押す」より「内側で守って固める」ために使いたい方位**です。」 | 30〜55字 |
| `close.neg` | 凶のしめ | 凶門:「人に会わず体を休める静養なら限定的に使えます。**「動いて整える」より「今日この方位を避ける」判断を優先したい方位**です。」／吉門:「どうしても使うなら、既習内容の整理にとどめたい日です。**「学びを進める」より「方位を変えて停滞を避ける」判断が必要な方位**です。」 | 55〜85字 |
| `gods.support` | 吉神・吉または△ | 「九地が入るため、派手に増やすより、結果を長く残る土台に変えやすい配置です。」テーマを問わず通じる内容で | 30〜55字 |
| `gods.muted` | 吉神・凶 | 「九天は本来、攻めと拡大の神ですが、この配置では力を出しきれません。」 | 30〜50字 |
| `gods.caution` | 凶神・吉。**「ただし、」で始める** | 「ただし、勾陳が入るため、手続きの停滞や話の長引きには注意が必要です。」 | 30〜50字 |
| `gods.weigh` | 凶神・△または凶 | 「勾陳が入るため、手続きの停滞や長引くもつれを見込みたい配置です。」 | 30〜50字 |
| `stars.*` | 神と同じ4種類 | 「天任は実直さを司る星で、誠実な頼みごとや紹介にもつながりやすい配置です。」「天蓬は日常の用事には重く働く星で、積み上げる場面では力を出しきれません。」星の文は**テーマを問わず通じる内容**にする（天心は「医薬と知略を司る星で、判断の精度を支えます」のように） | 30〜55字 |
| `vetoes.body` | △・凶の主な理由 | 「反吟の影響で予定が反転しやすく、変更や出戻りを見込みたい日です。」 | 30〜50字 |

| `vetoes.空亡.relief` | 空亡が吉門で和らぐとき | 「空亡の巡りのため、結果は少し遅れて届きやすい配置です。」 | 25〜45字 |

## 守ること

- 意味は v1 の同じ門・神・星・拒否権の文言（`general` `axes` `use` `actions` `phrase` `copresence` `caution` `exception` `label`）に沿う。
- 死門は「弔事・法事・お墓参り（ご縁）」「終わらせる・畳む・休むに徹する」以外を勧めない。死門の `head.pos` `close.pos` もこの範囲で書く。
- 凶門（杜門 傷門 驚門 死門）の pos / neu は、その門の限定的な使い道（v1 の `use` と `actions`）に絞って書く。何にでも良いとは書かない。
- 健康: 「治る」「効く」「改善する」など効果を言い切らない。受診や通院をやめさせるように読める文は書かない
  （凶のときは「この方位を使わない」であって「病院に行かない」ではない）。
- 「必ず」「絶対」は使わない。
- 次の言い回しは使わない: 「と安心」「すると良いでしょう」「してみましょう」「心がけましょう」「無理のない範囲で」「焦らずに」「ゆっくりと」
  「リラックスして」「かもしれません」「寄り添う」「あなたらしく」「大切にして」「うまく付き合っていきましょう」「意識してみて」
- `**` の太字は `close.*` の中の1か所だけ。他の部品には入れない。
- 同じ門の中で、head・body・close に同じ言い回しを繰り返さない（組み合わせたとき、くどくなるため）。
- 出力は**妥当な JSON**（コメントなし・末尾カンマなし・UTF-8）。書き終えたら JSON として読み込めることを確認する。
