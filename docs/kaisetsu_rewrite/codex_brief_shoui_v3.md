# 象意の文（v3）を書く依頼

奇門遁甲アプリの方位解説のうち、「象意（十干剋応・格局）」の1文を、です・ます調で書き直す。

- 承認済みの見本: `docs/kaisetsu_rewrite/approved_samples.md`
  （見本の中の「復見騰蛇により夫婦間のお金の話はこじれやすいため…」「金華水流により、待ち合わせや連絡のすれ違いには注意が必要です。」
  「貴人入獄により、上司や取引先への頼みごとは通りにくい配置です。」が、この依頼で書く文にあたる）
- 意味の出どころ: `data/kaisetsu/kaisetsu_bank_v1.json` の `shoui`（104種類。それぞれ `polarity` `phrase` `hint` `axes`、一部に `variants`）
- 他のファイルは読まなくてよい。コードは変更しない。**指定の JSON ファイルを1つ作るだけ。**

## 作るファイル: `data/kaisetsu/kaisetsu_bank_v3_shoui.json`

```jsonc
{
  "meta": { "version": "v3", "note": "象意のテーマ別の文（です・ます調）。意味は v1 に準拠" },
  "shoui": {
    "復見騰蛇": {
      "axes": {
        "goen": "…", "shigoto": "…", "kinun": "…", "kenko": "…", "benkyo": "…"
      }
    },
    "凶蛇入獄": {
      "axes": { 5テーマ },
      "variants": {                      // v1 に variants がある象意だけ。キーは v1 と同じ
        "62": { "axes": { 5テーマ } },
        "68": { "axes": { 5テーマ } }
      }
    }
  }
}
```

- v1 の `shoui` にある**104種類すべて**を、同じ名前・同じ順番で書く。抜け・追加は不可。
- v1 に `variants` がある象意（凶蛇入獄・華蓋蓬星・華蓋孛師）は、`variants` も同じキーで書く。

## 各文の書き方

- 1テーマにつき**1文**。です・ます調。文末は「。」。45〜75字。
- **「{象意の名前}により、」で始める。**
  - 例（凶・金運）: 「復見騰蛇により、夫婦間のお金の話はこじれやすいため、家計や大きな出費の相談は別の日に回したい配置です。」
  - 例（凶・ご縁）: 「金華水流により、待ち合わせのすれ違いや連絡の途絶えが起きやすいため、会う場所と時間は二重に確かめたい配置です。」
  - 例（吉・仕事）: 「青龍返首により、動いたぶんだけ大きな成果が出やすく、新規案件や独立・転職の一歩を強く後押しする配置です。」
- 意味・吉凶の向き（`polarity`）は v1 の同じ象意・同じテーマの `axes` の文に沿う。`axes` に書かれていない内容を足さない。
  - polarity が 1（吉）: 何がうまく運ぶかを言い切る
  - polarity が -1（凶）: 何が起きやすいか＋どう避けるか
  - polarity が 0: 条件つき・どちらにも働く、という v1 の書き方に沿う
- 文末の形は「〜配置です。」「〜しやすい日です。」「〜を後押しします。」「〜には注意が必要です。」など、同じ形ばかりにならないよう散らす。
- 健康: 「治る」「効く」「改善する」など効果を言い切らない。受診や通院をやめさせるように読める文は書かない。
- 「必ず」「絶対」は使わない。太字（`**`）は使わない。
- 次の言い回しは使わない: 「と安心」「すると良いでしょう」「してみましょう」「心がけましょう」「無理のない範囲で」「焦らずに」「ゆっくりと」
  「リラックスして」「かもしれません」「寄り添う」「あなたらしく」「大切にして」「うまく付き合っていきましょう」「意識してみて」
- 出力は**妥当な JSON**（コメントなし・末尾カンマなし・UTF-8）。書き終えたら、JSON として読み込めること、
  象意が104種類あること、各象意に5テーマがそろっていることを確認する。
