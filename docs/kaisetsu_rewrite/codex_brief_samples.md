# 解説文の書き直し：見本5本の依頼

奇門遁甲（方位の占い）アプリの「方位ごとの解説文」を、読みやすい文章に書き直したい。
まず見本を5本書いてほしい。ファイルの編集やコマンドの実行は不要。**文章だけを返すこと。**

読む人は占いを仕事にしている人や学んでいる人。ふわっとした励ましではなく、
「なぜそう言えるのか（どの要素がそう働くのか）」と「だからどう使うか」が分かる文章を求めている。

## 目標とする書き方（運営者が良いと言った見本）

> **金運は「増やす」より「育てる・守る」ことに向く方位です。**
>
> この日は伏吟の影響で、物事が停滞しやすく、大きな勝負や積極的な資金移動には向きません。一方で、足元を固めることには適しており、家計や資産の見直し、貯蓄、投資計画、仕入れの検討など、今あるお金を整えて将来の財につなげる行動には吉。
>
> また、太陰が巡るため、表立った動きよりも、水面下での交渉や根回し、信頼できる人からの支援を得ることにも向いています。
>
> 生気と財につながる吉門を活かし、**「一気に稼ぐ」よりも「お金が育つ土台をつくる」ために使いたい方位**です。

この見本の良いところ:
1. 1文目が、その方位の使い方を一言で言い切っている（太字）
2. 「〜の影響で → 一方で → また → だからこう使う」と理由がつながっている
3. です・ます調でそろっている
4. 最後に「どう使いたい方位か」でしめている（太字）

## 守ること

- 評価（◎ ○ △ ▲ ×）と文章の向きを必ず一致させる。
  - ◎ 大吉・○ 吉: 前向きに。ただし凶の要素があれば「〜には注意」と一言添える
  - △ どちらでもない: 「大きくは動かないが、これなら向く」
  - ▲ 凶・× 大凶: その用事にこの方位を使わないことを勧める。良い要素があっても「力を出しきれない」と書く。
    凶門の「〜なら使えます」という限定的な使い道だけは書いてよい
- 「材料」に書かれた要素（門・神・星・象意・拒否権）だけを使う。書かれていない要素を足さない。
- 要素の意味は「部品」の文言に沿う。意味を変えたり盛ったりしない。
- 次の言い回しは使わない:
  「と安心」「すると良いでしょう」「してみましょう」「心がけましょう」「無理のない範囲で」「焦らずに」「ゆっくりと」
  「リラックスして」「かもしれません」「寄り添う」「あなたらしく」「大切にして」「うまく付き合っていきましょう」「意識してみて」
- 健康の文で「治る」「効く」「改善する」など、効果を言い切らない。通院をやめさせるように読める文も書かない
  （× のときは「今日この方角を使わない」であって「病院に行かない」ではない）。
- 「必ず」「絶対」などの断定をしない。
- 1本 180〜260字。3〜4段落。太字は最初の1文と、最後のしめの中の1か所だけ。
- 門・神・星の名前（生門、太陰、天心 など）は文中に出してよい。象意の名前（復見騰蛇 など）は出さなくてよい。

## テーマの呼び方
goen=ご縁、shigoto=仕事、kinun=金運、kenko=健康、benkyo=勉強

## 書いてほしい5本（材料と、今の文）

`docs/kaisetsu_rewrite/samples_input.json` に5件ある（rank / axis / gate=門 / god=神 / star=星 / vetoes=拒否権 / shoui=象意 / current=今の文）。
各要素の意味は `docs/kaisetsu_rewrite/samples_parts.json`（部品）を見ること。

## 返し方

次の形で5本。前置きや解説は不要。

```
### 1. ◎ 金運
（本文）

### 2. ○ ご縁
（本文）
…
```

最後に「書いていて、部品の意味どうしがぶつかって困った点」があれば3行以内で書くこと。
