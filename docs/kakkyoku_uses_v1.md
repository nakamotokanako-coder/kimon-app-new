# 格局の用途（格局検索の「何をしたい？」） v1

2026-10-06 決定。格局検索（探す →「条件から探す」）を、格局の名前を知らない人でも使えるようにするための表。

## 考え方

- 「目的で選ぶ」は、盤全体からおすすめの方位を判定する。
- 「格局検索」は、その用途の特殊な吉格が出る日時を狙う。
- **講座の内容が主**。用途は、象意辞書（`data/shoui_dict.json` の original / practical。講座の中身）に書いてある使い道から拾う。
- **古典・現行の解説は補足**。講座と食い違わず、今の暮らしで使える用途だけを「古典：〜」として足す。
  雨乞い・伏兵・水戦など、今は使わない用途は入れない。
- 効果は約束しない。「願いが叶う」とは書かず、「〜に」と書く。

## 象意辞書について

盤・地図の詳しい画面に出る格局の説明（象意辞書）は、講座の中身なので変えない。
検索の画面の一言・札は、その辞書の文を短くしたもの。古典の補足は検索の画面にだけ出す。
