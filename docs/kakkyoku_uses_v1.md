# 格局の「伝統的な代表用途」 v1

2026-10-06 決定。格局検索（探す →「条件から探す」）を、格局の名前を知らない人でも使えるようにするための表。

## 考え方

- 「目的で選ぶ」は、盤全体からおすすめの方位を判定する。
- 「格局検索」は、その用途に使われてきた特殊な吉格が出る日時を狙う。
- 資料や流派で、格局の成立条件・用途には差がある。アプリでは「伝統的な代表用途」として出す。
- 効果は約束しない。「この日に神社へ行けば願いが叶う」とは書かず、「神社参拝・祈願・願掛けに」と書く。

## 残課題：象意辞書との食い違い

盤・地図の詳しい画面に出る格局の説明は、象意辞書（`data/shoui_dict.json`）の文をそのまま使っている。
次の格局は、辞書の文と上の表で、用途の向きが違う。今回は辞書を変えていない（検索の画面だけ、上の表の一言を出す）。

| 格局 | 辞書（practical） | この表 |
|---|---|---|
| 神遁 | ひらめき型の企画、運の要素が大きい場面 | 神社参拝・祈願・願掛け |
| 地遁 | 長期案件、勤続評価、地道な学習の成果発表 | 建築・修繕・基盤づくり |
| 雲遁 | 戦略的な交渉、競合分析 | 雨乞い・ひそかに進めること |
| 龍遁 | 海外取引、物流、ネット配信 | 水に関すること・橋や井戸 |
| 虎遁 | 強気の交渉、撤退戦、債権回収 | 家を守る・建築・厄除け |
| 鬼遁 | 競合の隙を突く施策、差別化戦略 | 調査・情報収集 |

辞書をこの表に合わせて書き直すかどうかは、辞書の出どころ（講座の文か、あとから足した現代語訳か）を確かめてから決める。
